# 📦 Smart Inventory System

A full-stack inventory management system developed during my **Aurora Training**. The project was built to help businesses manage their inventory more efficiently through a simple and modern web application.

The system allows users to manage products, categories, suppliers, and inventory while providing a clean dashboard for monitoring stock and daily operations.

---

## ✨ Features

- Secure user authentication
- Dashboard with inventory overview
- Product management (Add, Edit, Delete)
- Category management
- Supplier management
- Inventory tracking
- Search and filtering
- Email notifications
- Responsive user interface

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AseelAbdElhaq/aurora-training-smart-inventory-system.git
```

### Run the backend

```bash
cd smart-inventory-backend
mvn spring-boot:run
```

The backend will start on:

```
http://localhost:8080
```

### Run the frontend

```bash
cd smart-inventory-frontend
npm install
ng serve
```

Open your browser and visit:

```
http://localhost:4200
```
